# Timeline 宣传视频

本目录保存两个可重新渲染的宣传片版本。均为 1920×1080、60fps、H.264 / AAC 横屏视频，使用中文文案与原创界面音效，无旁白。所有对话均为虚构演示内容。

## 参考版第二次调整：定位与音效选择

根据反馈放大右侧时间线：普通刻度由 14 调为 24，悬停与返回刻度由 28 调为 46，中心距由 13 调为 22。刻度整体向聊天内容移动 66。以上坐标为 1600×900 画布单位，导出时等比例放大。

黄色返回刻度按照插入槽位计算中心。此前在后续节点向下移动一个间距后，返回刻度仍按半格计算，导致上下留白不等；现在黄色刻度与上下问题刻度等距，所有刻度使用同一右端与垂直中心计算。点击后光标移开，避免覆盖黄色横线。

提供三种新的原创音效，均使用 `reference-timing.mjs` 的操作时间：

| 版本 | 声音 |
| --- | --- |
| A：干净点击 | 短按键与纸面滑动，声音干燥、停顿清楚 |
| B：柔和轻触 | 柔软触碰与轻气流，减少尖锐音头 |
| C：轻电子声 | 短电子点按与升降滑音，结果有清亮确认 |

在本目录依次运行：

```text
npm run reference:v2
npm run reference:audio-options
```

第二版画面输出到 `renders/reference-v2/full.mp4`。三种完整成片及相同的 9.4 秒试听片输出到 `renders/reference-v2/audio-options/`。试听截取 12.9–22.3 秒，包含界面展开、发送、生成返回点、结果显示、返回原文和收拢。

`reference-audio-options.mjs` 将三版音量匹配到共同的实际响度，检查编码后差异不超过 0.3 LUFS。试听片单独匹配音量，避免截段后不同的动作密度影响比较。整片复用原视频流，试听片也复用同一个截段视频流，并通过 SHA-256 验证画面一致。三种完整视频均可直接使用；当前没有替用户选定声音。

本机三种完整视频及试听片保存到 `D:/Desktop/Timeline-宣传片-v2/`。三种成片分别完整解码通过：24 秒、1440 帧；三种试听片分别通过：9.4 秒、564 帧。成片响度分别为 −21.23、−21.13、−21.02 LUFS，最大差异 0.21 LUFS；试听片分别为 −22.50、−22.50、−22.51 LUFS，差异 0.01 LUFS。所有编码后的真峰值最高为 −2.4 dBTP，无削波。已核对 10 个编码后关键状态，以及黄色返回刻度的右端对齐与 22 单位等间距。

## 参考视频版（24 秒）

根据用户提供的 `10月10日.mp4` 制作。实际读取了参考片的尺寸、时长和连续动作：原片为 1600×900、30fps、约 22.93 秒。沿用浅灰背景、中心组件展开、功能章节胶囊、光标操作、结果停顿和收拢结尾，按 Timeline 的真实功能重绘内容。参考文件不复制到仓库。

只演示当前启用的 ChatGPT 时间线能力：悬停预览提问、点击刻度跳转，以及发送新问题后自动保留原阅读位置并点击黄色刻度返回。黄色位置与提问共用轨道。回答旁的短黄色线仅用于影片强调阅读位置；它不是新增的产品控件。

| 秒数 | 内容 |
| --- | --- |
| 0–1.55 | Timeline 品牌胶囊与短文案 |
| 1.55–5.15 | 同一组件展开为对话页，滚动长对话，生成刻度 |
| 5.15–10.75 | 悬停预览问题，点击刻度，回到原提问 |
| 10.75–12.9 | 对话页收拢为黄色功能胶囊，切换返回位置示例 |
| 12.9–19.25 | 回看前文，在底部输入并发送，生成回答与返回刻度 |
| 19.25–21.2 | 点击黄色刻度，返回追问前的原段落 |
| 21.2–24 | 收拢为品牌胶囊，展示产品名与开源项目入口 |

在本目录运行：

```text
npm run reference:stills
npm run reference:export
```

成片输出到 `renders/reference-cut/full.mp4`。本机预览运行 `npm run preview`，在地址末尾添加 `?scene=reference`。预览与导出共用 `reference-scene.mjs`；文案在 `reference-copy.json`，音效事件在 `reference-timing.mjs`，原创音效在 `audio/reference.mjs`。

若只修改本版声音，可复用画面：

```text
npm run audio -- --scene reference-scene.mjs --style reference --video renders/reference-cut/full.mp4 --output renders/reference-cut/new-audio.mp4
```

## 修改与导出

本目录是独立的媒体工程，不参与浏览器扩展运行，也不改变根目录的依赖或构建方式。

在本目录运行 `npm ci`。设置 `fonts.json` 为本机中文字体；`.fonts/` 是本机字体子集，不分发系统字体。设置环境变量 `FFMPEG_PATH` 为本机 FFmpeg 路径，或者保证 `ffmpeg` 在 PATH 中。

- `npm run preview`：本机实时预览画面，可拖动时间轴；完整音效在导出的 MP4 中。
- `npm run stills`：导出关键帧。
- `npm run export`：导出 `renders/full.mp4`，并完整解码验证帧数、音轨与峰值。
- `copy.json`：中文文案与演示对话。
- `scene.mjs`：确定性的界面与动画。
- `timing.mjs`：画面动作对应的音效事件。
- `audio/b.mjs`：原创音效合成。

如只修改声音，运行 `npm run audio -- --video renders/full.mp4 --output renders/new-audio.mp4`，复用原视频流，避免再次渲染画面。

本机成片、音轨、字体、预览帧和依赖均被忽略；Git 保存可重新渲染的源码与制作说明。
