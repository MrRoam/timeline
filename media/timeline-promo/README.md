# Timeline 宣传视频

成片为 36 秒、1920×1080、60fps、H.264 / AAC 的横屏视频。中文文案，无旁白，原创界面音效。所有对话均为虚构演示内容。

## 展示范围

按本仓库 `manifest.json` 与实际时间线逻辑制作。只展示 ChatGPT 中可以直接操作的能力：悬停预览提问、点击刻度跳转、固定阅读位置、发送后保留返回点。没有展示已移除的问题列表入口、单条收藏入口或停用的平台。

动画按真实位置重绘界面，是功能演示动画。输入框留在底部，发送按钮命中后消息进入对话；黄色返回刻度与问题刻度共用轨道。自动返回点示例使用明确的章节过渡，避免混淆已有手动标记与新返回点。

## 时间线

| 秒数 | 内容 |
| --- | --- |
| 0–3 | 长对话的定位问题 |
| 3–12 | 刻度转入对话页，悬停预览，点击跳转 |
| 12–19 | 标记位置，浏览别处，回到原阅读段落 |
| 19–21 | 明确切换到自动返回点示例 |
| 21–30 | 底部输入、发送跳底、自动留下返回点、返回原文 |
| 30–36 | 收拢刻度，品牌与开源项目入口 |

## 修改与导出

本目录是独立的媒体工程，不参与浏览器扩展运行，也不改变根目录的依赖或构建方式。

在本目录运行 `npm ci`。设置 `fonts.json` 为本机中文字体；`.fonts/` 是本机字体子集，不分发系统字体。设置环境变量 `FFMPEG_PATH` 为本机 FFmpeg 路径，或者保证 `ffmpeg` 在 PATH 中。

- `npm run preview`：本机实时预览画面，可拖动时间轴；完整音效在导出的 MP4 中。
- `npm run stills`：导出关键帧。
- `npm run export`：导出 `renders/full.mp4`，并完整解码验证帧数、音轨与峰值。
- `copy.json`：中文文案与演示对话。
- `scene.mjs`：确定性的界面与动画。
- `timing.mjs`：画面动作对应的音效事件。
- `audio/b.mjs`：原创音效合成。

如只修改声音，运行 `npm run audio -- --video renders/full.mp4 --output renders/new-audio.mp4`，复用原视频流，避免再次渲染画面。

本机成片、音轨、字体、预览帧和依赖均被忽略；Git 保存可重新渲染的源码与制作说明。
