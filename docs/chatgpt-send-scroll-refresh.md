# 发送后的阅读位置与新提问刷新

修复版本：`4.6.18`，日期：2026-10-07。

## 行为

发送问题后，若 ChatGPT 把页面自动滚到底部或新提问的位置，时间线会保存发送前的阅读位置。点击黄色返回点即可回到该位置。仍在阅读最后一段长回答、对话只有一次提问、页面先滚动再挂载新问题时也适用。

已有临时 Pin 时，保留原 Pin，并沿用六秒闪烁候选点的确认方式。用户主动滚动或点击时间线导航会取消尚未确认的自动跳转判断。已经位于底部时不新增返回点。

新提问通过稳定的 `main` 范围监听发现；即使新消息插在旧消息容器之外，也会重新绑定容器。虚拟化空壳、晚到的角色标题和提问正文均能触发更新。持续变化时，刷新等待不超过 500 毫秒，不必等待回答输出结束。

## 原因

原来的跳底判断用最后一个激活问题代替实际底部，并且必须等提问数量增加后才能捕获位置。点击事件记录也可能晚于聚焦导致的滚动。现在提前监听发送按钮的 `pointerdown`、输入框发送按键和表单提交，优先按实际滚动尺寸确认跳转，并排除换行、输入法确认和停止生成。

原来的观察范围是已知提问的共同祖先，新消息可能出现在这个范围之外。虚拟化角色只向前倒推，末尾先出现的空壳也可能没有角色。现在扩大结构监听范围，补齐末尾轮次，并为持续结构变化设置刷新期限。

## 更新与验证

运行 `node scripts/build-chrome.js` 会更新 `dist/chrome-unpacked` 并生成 `AIChatTimeline-v4.6.18-chrome.zip`。在扩展管理页重新加载原有扩展，确认版本为 `4.6.18`，随后刷新 ChatGPT 标签页。保留原加载路径即可沿用原有收藏与设置。
